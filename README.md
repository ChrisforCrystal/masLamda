# ⚡ masLambda - 极速 Wasm Serverless 运行时

**masLambda** 是一个高性能、轻量级的 Serverless 计算平台，旨在提供毫秒级的冷启动体验和原生安全沙箱。

它采用经典的 **控制面 (Go) + 数据面 (Rust)** 分离架构，支持 WebAssembly (Wasm) 模块的动态上传与执行。

## 🚀 核心特性

- **极速冷启动**: 基于 `wasmtime` 和 SHA256 模块缓存，实现 <1ms 的热调用延迟。
- **原生安全**: 默认开启沙箱隔离，并通过 Fuel (燃料) 机制防止死循环和资源滥用。
- **多语言支持**: 支持 Rust, C++, Go, AssemblyScript 等任何能编译为 Wasm 的语言。
- **可视化控制台**: 提供 Web Dashboard，支持拖拽上传插件和实时监控集群状态。
- **高性能通信**: 组件间使用 gRPC 进行低延迟通信。

## 🛠️ 环境要求

在运行本项目之前，请确保你的环境已安装：

- **Rust**: `cargo` (用于编译 Runner)
- **Go**: `go 1.20+` (用于编译 Controller)
- **Protobuf**: `protoc` (可选，仅在修改 `.proto` 文件时需要)

## 🏁 快速开始 (Quick Start)

我们提供了一键启动脚本，可以同时启动 Runner 和 Controller，并打开 Dashboard。

```bash
./start_dashboard.sh
```

启动成功后，打开浏览器访问：

👉 **http://localhost:8999/dashboard**

你可以在 Dashboard 中：
1.  **上传插件**: 将 `.wasm` 或 `.wat` 文件拖入上传区。
2.  **查看状态**: 实时查看集群节点的健康状况。

## 📡 API 使用示例

### 0. 准备 Wasm 产物 (编译示例)
在使用 API 之前，你需要先编译示例项目 (Calculator) 生成 `.wasm` 文件：

```bash
cd calculator
cargo build --target wasm32-wasi --release
cp target/wasm32-wasi/release/calculator.wasm ../
cd ..
```

### 1. 部署服务
```bash
curl -X POST http://localhost:8999/deploy \
  -F "file=@calculator.wasm"
# 返回: {"id": "service-uuid", "status": "Running"}
```

### 2. 调用服务 (JSON-RPC)
```bash
curl -X POST http://localhost:8999/services/<SERVICE_ID>/invoke \
  -d '{"method": "add", "params": {"a": 1, "b": 2}}'
# 返回: {"jsonrpc": "2.0", "id": "...", "result": 3}
```

### 3. 停止服务
```bash
curl -X POST http://localhost:8999/services/<SERVICE_ID>/stop
```
