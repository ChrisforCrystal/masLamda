# 张量并行 (Tensor Parallelism) 图解：以列切分 (Column Parallel) 为例

很多同学对 "竖着切" (Column Partition) 感到困惑。让我们用最直观的矩阵乘法图解来看。

## 1. 我们的目标

我们要计算 `Y = X * W`。

假设：

- 输入 `X` 是 `[1, 4]` 的向量（为了简单，Batch Size=1）。
- 权重 `W` 是 `[4, 8]` 的大矩阵。
- 输出 `Y` 是 `[1, 8]` 的向量。

## 2. 单卡计算 (没有并行)

```text
      X (1x4)               W (4x8)                      Y (1x8)
[x1, x2, x3, x4]  *  [w11, w12 ... w18]  =  [y1, y2, y3, y4, y5, y6, y7, y8]
                     [w21, w22 ... w28]
                     [w31, w32 ... w38]
                     [w41, w42 ... w48]
```

## 3. TP 列切分 (Column Parallel)

我们把大矩阵 `W` **竖着切一刀**，分给 **Rank 0** 和 **Rank 1**。

### Rank 0 拿到了 W1 (左边 4 列)

```text
      X (1x4)              W1 (4x4)                    Y1 (1x4)
[x1, x2, x3, x4]  *  [w11, w12, w13, w14]  =  [y1, y2, y3, y4]
                     [w21, w22, w23, w24]
                     [w31, w32, w33, w34]
                     [w41, w42, w43, w44]
```

> Rank 0 算出的是最终结果 `Y` 的 **左半部分**。

### Rank 1 拿到了 W2 (右边 4 列)

```text
      X (1x4)              W2 (4x4)                    Y2 (1x4)
[x1, x2, x3, x4]  *  [w15, w16, w17, w18]  =  [y5, y6, y7, y8]
                     [w25, w26, w27, w28]
                     [w35, w36, w37, w38]
                     [w45, w46, w47, w48]
```

> Rank 1 算出的是最终结果 `Y` 的 **右半部分**。

## 4. 最后的汇聚 (All-Gather)

大家算完后，手里只有一半答案。

- Rank 0 手里有 `[y1...y4]`
- Rank 1 手里有 `[y5...y8]`

这时候调用 `dist.all_gather`：

- Rank 0 把 `[y1...y4]` 给 Rank 1
- Rank 1 把 `[y5...y8]` 给 Rank 0

结果大家都拼出了完整的 `Y`:

```text
Y = [y1, y2, y3, y4] + [y5, y6, y7, y8]
  = [y1, y2, y3, y4, y5, y6, y7, y8]
```

这就是代码里 `torch.cat(..., dim=1)` 的含义 —— 横着拼起来。
